# vujavujavuja.github.io

My first personal site, built with SvelteKit and Tailwind CSS in early 2024: a landing page with skills, projects, about and contact sections.

It has since been replaced by a newer site (see the [vujicai](https://github.com/Vujavujavuja/vujicai) repo). This one stays up as an archive.

## Run it locally

```bash
npm install
npm run dev
```

## Stack

SvelteKit 2, Svelte 4, Tailwind CSS, Vanta/three.js for the animated background.
